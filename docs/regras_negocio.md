Cada usuário deve possuir um `id_usuario` único.
Cada serviço deve possuir um `id_servico` único.
Cada chatbot deve possuir um `id_chatbot` único.
Cada conversa deve possuir um `id_conversa` único.
Cada mensagem deve possuir um `id_mensagem` único.
Uma conversa deve estar relacionada a um usuário e a um chatbot.
Uma mensagem deve estar relacionada a uma conversa.
O cadastro de um serviço deve permitir consultar seu nome, localização e informações de atendimento.
O sistema deve permitir consultar serviços que oferecem atendimento sem julgamento moral.
As informações de crise e as técnicas de respiração pertencem ao suporte oferecido pelo chatbot.
Os dados de teste devem ser fictícios e coerentes com o funcionamento do projeto.
