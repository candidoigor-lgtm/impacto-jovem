O projeto Conexão com Serviços de Saúde (Sem Estigma) tem como objetivo facilitar o acesso a informações sobre serviços de saúde e oferecer suporte por meio de um chatbot.
O sistema permite consultar serviços de saúde, suas informações de atendimento e localização, além de registrar conversas e mensagens do usuário com o chatbot.
O banco de dados armazena os dados necessários para organizar usuários, serviços de saúde, conversas e mensagens.
